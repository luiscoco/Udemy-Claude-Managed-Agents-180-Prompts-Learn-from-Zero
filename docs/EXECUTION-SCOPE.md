# What these applications execute

These labs teach agent application behavior. Distinguishing a local exercise from a hosted integration is part of the course.

## Foundation lessons

Lessons 1–8 have their own implementations and fixtures. Some include optional live adapters or account-backed commands. The default classroom exercises and included tests use synthetic data. Each lesson's README states its supported modes and what remains to be verified with a real account.

Lesson 1, for example, performs actual local sentence extraction in Classroom demo. Its three product traces illustrate different execution flows. Live Claude mode uses separate real SDK adapters and requires the corresponding account configuration.

## Lessons 9–180 and the combined browser

Provider operations, account entitlements, remote MCP servers, cloud deployment schedules, credential vaults and external delivery are simulated locally. IDs starting with `demo_` are classroom identifiers. Cost, latency, usage and capacity values labelled as fixture data are synthetic.

Some operations perform real local work:

- SQL exercises execute SQLite queries.
- REST exercises call a local HTTP fixture.
- Browser exercises run Playwright against a controlled HTML page.
- Worker exercises create local markers inside disposable `.runtime` directories.
- Webhook exercises calculate and verify HMAC signatures using a synthetic classroom protocol and key.
- Artifact exercises serve prebuilt classroom DOCX, PPTX, XLSX and PDF files. These are fixtures, not documents generated by a hosted model during the exercise.

Repository publication and report-delivery exercises stop at simulated results or local outboxes. They do not publish to your account or send external messages.

## Read code labels carefully

The interface separates **reference snippets** from **executing local handlers**. Provider reference snippets illustrate integration concepts; they are not evidence that the snippet has successfully run against a live service. Feature availability, preview access and real account behavior must be checked before a live integration.

## Validation limits

The original course workspace includes historical checks and recordings. This student repository excludes those large instructor artifacts. Included tests can be rerun against your installed dependencies and browser. A passing classroom test verifies that exercise; it does not establish production readiness, real provider performance or live account permissions.

See [repository validation](VALIDATION.md) for checks performed when preparing this student package.
