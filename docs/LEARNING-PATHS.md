# Choose your learning path

Use the [full curriculum](CURRICULUM.md) to open each numbered application. These routes are study suggestions, not promises about how quickly you will finish.

## Build a foundation

Complete Lessons 1–8 in order. Explain the difference between an agent definition, an environment, a session and an event. Then study Lessons 9–18 and change an agent definition while preserving the intended version behavior.

## Understand runtime behavior

Study Lessons 27–46. Trace a session from creation to completion, inspect streaming events, explore interruptions and explain how you would reconnect without confusing historical and new events.

## Design tools and integrations

Study Lessons 47–80. Focus on tool schemas, input validation, failures, MCP boundaries and approval policies. Write down one rejected input and the corrected version for each exercise you complete.

## Explore memory and collaboration

Study Lessons 107–136. Compare memory reads and writes, conflicts, specialists, threads and dynamic workflows. Treat research-preview topics as course snapshots and verify availability before a live implementation.

## Think about operations

Study Lessons 137–170. Follow the connections among outcomes, schedules, webhook delivery, observability, budgets and sandbox choices. Describe which controls would need enforcement outside the classroom application.

## Complete the project sequence

Work through Lessons 171–180 after the relevant foundations. For each project, sketch its inputs, actions, approvals, outputs and failure paths. Extend one local behavior and verify it with an appropriate existing test or a focused new assertion.
