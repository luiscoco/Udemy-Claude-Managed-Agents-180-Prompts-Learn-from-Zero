# Questions and improvements

For setup help, read [SETUP.md](docs/SETUP.md). For an application bug, open an issue with the lesson number, OS, Node.js version, reproduction steps, expected result and sanitised actual result.

Keep changes focused on a specific exercise. Preserve locally served syntax highlighting, accurate language labels, light/dark themes and presentation mode. Check the affected lesson's TypeScript and run relevant tests before proposing a change.

Do not commit `.env` files, credentials, private documents, runtime state, generated recordings or dependency folders. Reference snippets and classroom handlers must remain clearly distinguishable.
