# Practical application index

All 180 applications are included. Each lesson contains source, frontend assets, tests, a dependency lockfile and its own instructions.

[Browse the full curriculum](../docs/CURRICULUM.md) · [Start here](../README.md)

Choose a lesson from the repository root:

```shell
npm run setup -- 1
npm start -- 1
```

Replace `1` with any number from `1` to `180`. Stop the server with Ctrl+C before starting another lesson.
