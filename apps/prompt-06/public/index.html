Follow the workflow in Claude Console

Open Claude Console ↗
Configure an agent

Open the Managed Agents builder. Choose the model, write system instructions and review enabled tools, permissions, MCP servers and skills.

Test a session

Choose your environment and submit a test task in the inline runner. Inspect messages, tool activity and the session's stop reason.

Capture the configuration

Record the equivalent API request shown by Console, the agent and environment IDs, environment settings and the exact test input.

Run from your application

Reference the saved agent ID to reuse it, or create a new agent from the captured request. Run the same task and compare configuration and observed events.
